% Format du papier : mediane des images de page a 300 dpi, une fois
% otee la marge de numerisation.  117,2 x 176,9 mm mesures sur l'image

% chaque cote.  On retient un in-16 courant de 116 x 182 mm.
\newcommand{\VUpapierLargeur}{116mm}
\newcommand{\VUpapierHauteur}{182mm}

% Justification : mediane sur 223 pages a >= 25 lignes = 91,69 mm,
% ecart-type 1,36 mm (la dispersion vient du scan, pas de l'imprime).
\newcommand{\VUtexteLargeur}{91.69mm}

% Deux ordonnees mesurees, comptees depuis le bord superieur du papier :
%   - le folio       : mediane 221 px = 18,71 mm ;
%   - la 1re ligne du corps de texte : mediane 287 px = 24,30 mm.
% Le texte courant commence donc a 24,30 mm ; le folio est place au-dessus,
% en hauteur nulle, a son ordonnee propre.
\newcommand{\VUfolioY}{18.71mm}
\newcommand{\VUmargeSup}{24.30mm}
% Hauteur du bloc : du haut du folio (18,71) au bas de la derniere ligne
% (mediane 1850 px = 156,63 mm).
\newcommand{\VUtexteHauteur}{132.4mm}

% -------------------------------------------------------------------
% 2. CORPS ET INTERLIGNAGE
% -------------------------------------------------------------------
% Interlignage du texte courant.
%
% CETTE VALEUR ETAIT FAUSSE DE 0,11 pt, ET C'EST LE CONTROLE 11 QUI L'A
% MONTREE. Le premier releve prenait le MODE DES HAUTS DE LIGNE sur 85
% pages : 41 px a 300 dpi, soit 9,88 pt. Mais le haut d'une ligne depend
% des ascendantes qu'elle porte, et le mode d'une grandeur bruitee tombe
% sur l'entier le plus proche : 41 px n'etait pas une mesure, c'etait un
% arrondi. Mesure sur les LIGNES DE BASE (outils/lignesbase.py), qui ne
% dependent d'aucune lettre particuliere, le pas vaut 41,45 px sur les
% feuillets 20, 24, 30, 32, 37, 38 -- et 41,26 a 41,44 px sur les six
% feuillets 62 a 67. 41,45 px = 9,986 pt.
%
% L'ecart de 0,43 px par ligne ne se voit pas sur une ligne ; sur les
% quarante d'une page il fait 17 px, soit 1,4 mm, et c'est exactement le
% residu que neuf pages gardaient sans qu'on sut d'ou il venait. Pose a
% 9,99 pt, il tombe : dix pages en echec au controle 11, cinq apres.
% Essais voisins : 9,94 pt en laisse huit, 9,96 pt cinq, 10,02 pt sept.
% On retient la valeur MESUREE, non la meilleure du balayage.
\newcommand{\VUinterligne}{9.99pt}

% Corps du texte courant : la hauteur d'x mesuree vaut 1,729 mm
% (4,92 pt TeX) ; la largeur naturelle des lignes releveest de 260,7 pt.
% Les deux criteres donnent 10,2 pt pour XCharter (cf. LISEZ-MOI).
\newcommand{\VUcorps}{10.2pt}

% Notes : hauteur d'x 1,329 mm, soit 0,766 fois celle du corps, ce qui
% donne 7,81 pt ; pas des lignes 33,25 px = 8,01 pt.
\newcommand{\VUcorpsNote}{7.85pt}
\newcommand{\VUinterligneNote}{8.01pt}

% LES NOTES SONT INTERLETTREES.
% Deux mesures se contredisaient : la hauteur d'x donnait 7,8 pt pour le
% corps des notes, la largeur des lignes en reclamait 9,3. Aucun corps ne
% satisfait les deux — parce que l'original ne joue pas sur le corps mais
% sur l'approche : les notes sont composees interlettrees, usage courant
% pour le petit texte de cette epoque.
% Sans cela, mes lignes de note naissaient 15 % trop courtes et TeX
% comblait en etirant les espaces-mots, qui devenaient beants.
% Mesure sur quatre lignes de note entierement romaines du folio 14 :
% +77, +83, +79, +75 millièmes de cadratin. Mediane retenue : +78.
\newcommand{\VUtrackingNote}{78}

% L'ESPACE-MOT, mesuree et non heritee de la fonte.
% Blancs inter-mots du fac-simile, sur 2011 echantillons pris dans les
% lignes pleines de six pages : mediane 19,0 px = 4,58 pt, soit 0,449 du
% corps. XCharter, lui, donne 2,84 pt d'espace et 1,42 pt d'etirement :
% son plafond est a 4,26 pt, EN DESSOUS de ce que l'original emploie au
% repos. Mes lignes ne pouvaient donc pas se remplir : TeX les laissait
% courtes (sept « Underfull \hbox ») a 94 % de la justification, et le
% controle 10 les signalait sans que je comprenne pourquoi.
% C'est un poste de calibration que j'avais omis : j'avais mesure le
% corps, jamais la chasse des blancs.
%
% MAIS 4,58 pt est la valeur APRES justification, non au repos : j'ai
% mesure le resultat, pas le reglage. Pose telle quelle, elle fait
% deborder les lignes qui tenaient (48 echecs contre 7). On garde donc
% une largeur proche de celle de la fonte, avec une elasticite large,
% qui laisse chaque ligne trouver sa mesure. Cela ramene les
% « Underfull \hbox » de sept a deux — mais n'explique PAS les lignes a
% 94 % : le resultat est insensible au reglage sur trois valeurs
% essayees. L'hypothese est donc refutee, et la cause reste inconnue.
\newcommand{\VUespaceRatio}{0.32}
\newcommand{\VUespaceEtire}{0.30}
\newcommand{\VUespaceSerre}{0.14}

% -------------------------------------------------------------------
% 3. FONTE
% -------------------------------------------------------------------
% Le fac-simile est compose dans une romaine de transition a fort oeil,
% empattements fins et horizontaux, axe vertical.  Parmi les fontes
% disponibles, XCharter reproduit a la fois la hauteur d'x et la chasse
% (cf. outils/fontes.tex et outils/comparfontes.tex).
\newcommand{\VUfonte}{XCharter-TLF}

% LE GRAS VIENT D'UNE AUTRE FAMILLE, et c'est deliberé.
% Le gras du fac-simile est un demi-gras etroit, comme il est d'usage
% dans les fontes allemandes et luxembourgeoises de l'epoque : il n'est
% pas proportionne a son romain. Le gras de XCharter, lui, est large.
% Mesure sur le folio 12, ligne « la chefa esforco di la voco : ... » :
% le passage gras occupe 575 px = 138,5 pt au fac-simile, contre
% 151,4 pt en XCharter gras a 10,2 pt, soit 9 % de trop — assez pour
% que « neutra. » ne tienne plus dans la ligne.
% Deux remedes possibles, tous deux essayes :
%   - garder XCharter gras et le reduire : il faut descendre a 9,2 pt,
%     soit -10 %, ce qui se voit (les capitales grasses rapetissent) ;
%   - prendre un gras plus etroit : newtx gras donne 141,5 pt a 10,2 pt,
%     et tombe donc juste a 10,0 pt, a -2 % seulement, avec une hauteur
%     de capitale a 1,4 % de la mesure.
% C'est le second qui est retenu.
\newcommand{\VUfonteGras}{ntxtlf}
% Le gras est defini par un RAPPORT au corps courant, non par un corps
% absolu : 10,0 / 10,2 = 0,98. Fixe en dur, il composait les lettres
% grasses des notes (corps 7,9 pt) a 10 pt, ou elles sautaient aux yeux.
\newcommand{\VUratioGras}{0.98}

% 5. COUPURES DE LIGNE EXPLICITES
% -------------------------------------------------------------------
% \nl : fin de ligne SANS trait d'union.
% \cc : fin de ligne AVEC trait d'union (le trait est compose).
% On n'utilise jamais \\ : il annule la justification de la ligne.
\newcommand{\nl}{\penalty-10000\relax}
\newcommand{\cc}{-\penalty-10000\relax}
% \parplein TERMINE un alinea dont la derniere ligne court jusqu'a la
% marge — cas d'un alinea qui se poursuit sur la page suivante. Il
% remplace la ligne blanche qui termine un alinea ordinaire.
%
% \parfillskip est un parametre GLOBAL : pose une fois, il justifiait la
% derniere ligne de tous les alineas suivants de la page (folio 15 :
% « Rose Germana, rosa Italiana. » et les autres se retrouvaient tires
% jusqu'a la marge). On l'enferme donc dans un groupe, referme aussitot
% apres le \par qui l'utilise.
\newcommand{\parplein}{{\parfillskip=0pt\relax\par}}

% \VUcontinue OUVRE un alinea qui continue la page precedente : pas de
% renfoncement, la ligne reprend au fer a gauche.
\newcommand{\VUcontinue}{\noindent}

% \VUauFer{recul}{matiere} : une ligne calee A DROITE, mais a une
% distance MESUREE de la marge — c'est ainsi que le fac-simile pose les
% deux signatures du folio 8 (« L. DE BEAUFRONT. » a 41 px de la marge,
% « L. B. » a 43 px). Le recul est le meme aux deux a 2 px pres : c'est
% un cadratin voulu, non un hasard de justification.
% \parfillskip doit etre annule DANS le groupe, faute de quoi il se
% partage la place avec le \hfill et la ligne se centre.
\newcommand{\VUauFer}[2]{{\parfillskip=0pt\relax
  \noindent\hspace*{\fill}#2\hspace*{#1}\par}}

% L'APPEL DE NOTE D'UN TITRE. Au folio 5 (feuillet 9) le titre « Averto »
% porte un « (1) » qui n'est ni gras ni au corps du titre : c'est le
% romain du texte courant, remonte de 13 px (1,10 mm) au-dessus de la
% ligne de base du titre. Titre et appel sont centres ENSEMBLE sur la
% justification, a un demi-pixel pres.
% #1 = ecart entre le titre et l'appel.
% L'appel n'est PAS interlettre : \textls[0] annule dans le groupe
% l'interlettrage du titre, qui vaut -105 au folio 5.
\newcommand{\VUtitreAppel}[2][1.5mm]{%
  \hspace{#1}\VUdecale{1.10mm}{{\normalfont\fontfamily{\VUfonte}%
  \fontsize{\VUcorps}{\VUcorps}\selectfont\textls[0]{#2}}}}

% Conserve sous son ancien nom, mais il ne doit plus servir : il fuit.
\newcommand{\parsuite}{\parfillskip=0pt\relax}

% Les espaces-mots sont INSECABLES.
%
% Sans cela, le modele fuit : \nl force bien une coupure a la fin de la
% ligne, mais n'empeche pas TeX d'en placer une AVANT si la matiere ne
% tient pas. Une ligne 0,7 % trop large se recoupait donc toute seule, en
% silence, sans meme produire d'« Overfull \hbox » — c'est arrive au
% folio 13. Les espaces rendus insecables, le seul point de coupure
% legal d'une ligne est celui que le releve a place : une ligne trop
% large devient un « Overfull \hbox », que le controle 1 inventorie.
% La faute passe du silence au bruit.
%
% Les espaces gardent toute leur elasticite : la justification est intacte.
% Le corps de l'espace-mot, defini HORS du groupe ou l'espace est active :
% ecrit a l'interieur, ses propres espaces devenaient des tokens actifs
% et le rappelaient — recursion infinie, « TeX capacity exceeded ».
\makeatletter\newcommand{\VUespaceMot}{%
  \ifdim\spaceskip=0pt\relax
    \@tempdimb=\f@size pt
    \hskip\VUespaceRatio\@tempdimb
      plus\VUespaceEtire\@tempdimb minus\VUespaceSerre\@tempdimb
  \else \hskip\spaceskip \fi}\makeatother
\begingroup
  \catcode`\ =\active
  \gdef\VUespacesInsecables{\catcode`\ =\active
    \def {\ifhmode\ifnum\lastnodetype>-1\relax\penalty10000\VUespaceMot\fi\fi}}%
\endgroup

% Aucune cesure decidee par TeX : toutes les coupures sont relevees.
\hyphenpenalty=10000
\exhyphenpenalty=10000
\pretolerance=-1
\tolerance=9999
\emergencystretch=0pt

% Chaque page du fac-simile est composee dans une minipage de hauteur
% fixe : une retouche dans un alinea ne peut pas faire migrer du texte
% vers la page suivante.
\pagestyle{empty}
\setlength{\parskip}{0pt}
\setlength{\topskip}{0pt}      % sinon la minipage deborde de \topskip
\raggedbottom
\newcommand{\VUalinea}{4.6mm}   % renfoncement mesure sur le fac-simile
\setlength{\parindent}{\VUalinea}

% #1 (optionnel) = numero de FEUILLET du fac-simile. Il n'est pas
% compose : il sert aux controles a retrouver la page du scan.
% #2 = folio imprime ; vide si la page n'en porte pas.
% -------------------------------------------------------------------
% LA MARQUE CACHEE, sur chaque page.
% Elle est composee en MODE DE RENDU 3 (« 3 Tr » du PostScript inclus
% dans le PDF) : le texte entre dans le flux de la page, il est indexe,
% cherchable et extrait par pdftotext, mais il n'est PAS PEINT — aucun
% pixel n'en sort a l'impression ni a l'ecran, a aucun grossissement.
% Ce n'est pas du blanc sur blanc, qui se verrait en selectionnant ou en
% changeant de fond : c'est du texte que le moteur de rendu saute.
% Par surcroit de precaution le corps est de 0,4 pt, et la boite qui la
% porte est de hauteur ET de largeur nulles : la marque ne peut deplacer
% aucun element de la page.
% Elle est posee par l'environnement VUpage, donc sur les 236 pages.
\newcommand{\VUmarque}{Gilles-Philippe Morin kompris, skanis e direktis
  la transskribo di ca libro.}
\newcommand{\VUmarqueCachee}{%
  \vbox to 0pt{%
    \hbox to 0pt{%
      \pdfliteral{3 Tr}%
      \fontsize{0.4pt}{0.4pt}\selectfont\VUmarque
      \pdfliteral{0 Tr}\hss}%
    \vss}%
  \nointerlineskip}

\newenvironment{VUpage}[2][]%
  {\par\noindent\begin{minipage}[t][\textheight][t]{\textwidth}%
     % minipage remet \parindent a zero (\@parboxrestore) : on le retablit,
     % le fac-simile renfonce tous ses alineas.
     \setlength{\parindent}{\VUalinea}%
     \VUespacesInsecables
     \VUtexte\VUmarqueCachee\VUfolio{#2}\ignorespaces}%
  {\end{minipage}\par\penalty-10000\relax}

% 6 bis. JUSTIFICATION VERTICALE DE LA PAGE
% -------------------------------------------------------------------
% Le compositeur justifie chaque page VERTICALEMENT : mesure faite sur
% les feuillets 20 a 39, la derniere ligne de base tombe a 145,3 mm
% sous le folio, a 0,3 mm pres, quel que soit le nombre de lignes.
% Quand la matiere ne suffit pas a remplir la page, il repartit le
% surplus en interlignage : il « carde » la page. Deux moyens, tous
% deux visibles au fac-simile :
%   -- des lames uniformes entre TOUTES les lignes du corps : le pas
%      passe de 41,45 px (interlignage normal, 9,88 pt) a la valeur
%      propre a la page (feuillet 34 : 43,10 px = 10,38 pt) ;
%   -- des blancs plus larges aux articulations : fin d'alinea,
%      debut d'enumeration, reprise du discours.
% Sans ces deux reglages la page derive verticalement de 40 a 140 px
% (3 a 12 mm) : le texte reste juste ligne a ligne, mais aucune ligne
% ne tombe en face de son modele. C'est le controle 11 qui le mesure.
%
% Interlignage propre a une page. A appeler juste apres \begin{VUpage},
% AVANT toute matiere. Sans appel, la page garde \VUinterligne.
\newcommand{\VUinterlignePage}[1]{%
  \fontsize{\VUcorps}{#1}\selectfont}
% Blanc ORDINAIRE entre deux alineas. Le fac-simile en met un partout :
% releve sur les feuillets 15 a 44, 27 des 32 exces mesures se serrent
% entre 7 et 9 px, mediane 7,71 px = 1,86 pt. Les autres valeurs sont
% franchement plus grandes (16 px et au-dela) et propres a leur page.
% Il n'est PAS mis en \parskip : au sommet d'une minipage la colle de
% \parskip subsiste et decalerait toute la page d'autant. On l'ecrit
% donc, comme les sauts de ligne, la ou il est.
\newcommand{\VUblancAlinea}{\vskip\VUblancAlineaValeur\relax}
\newcommand{\VUblancAlineaValeur}{1.86pt}
% Blanc plus large a une articulation (ouverture d'une enumeration,
% reprise du discours). #1 = l'EXCES mesure sur le pas regulier de la
% page, DIMINUE du blanc ordinaire ci-dessus quand il le remplace.
% Mesure : outils/cardage.py.
\newcommand{\VUblanc}[1]{\vskip #1\relax}

% -------------------------------------------------------------------
% 6 ter. TABLEAUX A ACCOLADES
% -------------------------------------------------------------------
% Le premier du volume est au folio 31 (« GRADI KOMPARALA. »). Il ne se
% laisse pas decrire par un tableau ordinaire : ses elements ne forment
% pas une grille. « Superlativo » et « de o ek » tombent A MI-HAUTEUR
% entre deux lignes, chacun centre sur la portee de l'accolade qui le
% designe. Les six lignes du tableau, elles, sont bien sur la grille du
% volume : lignes de base a 413, 454, 495 px pour le premier groupe,
% 561, 602,5, 643,5 px pour le second, soit le pas courant de 41 px.
%
% On garde donc la regle du volume — une ligne du fac-simile fait une
% ligne du compose — et on pose chaque element a l'abscisse relevee.
%
% \VUcase{abscisse}{matiere} : matiere posee a l'abscisse indiquee,
% comptee depuis la marge de gauche, sans largeur propre.
\newcommand{\VUcase}[2]{\hbox to 0pt{\hskip#1\relax#2\hss}}
% \VUrang{...} : UN rang du tableau, c'est-a-dire une ligne.
% Le rang entier est enferme dans une boite de la largeur du bloc.
% Une suite de \VUcase laissee libre dans le paragraphe ne tenait pas :
% a l'interieur de \VUpage — ou l'espace est active et l'espace-mot
% elastique — TeX trouvait a couper entre les boites, et chaque element
% du tableau descendait d'une ligne, en escalier. Enfermes dans une
% boite, ils n'offrent plus aucun point de coupure.
\newcommand{\VUrang}[1]{\hbox to \textwidth{#1\hfil}\penalty-10000\relax}
% \VUdecale{hauteur}{matiere} : pour ce qui est pose entre deux lignes.
\newcommand{\VUdecale}[2]{\raisebox{#1}[0pt][0pt]{#2}}
% Accolades. Celles du fac-simile sont de la fonte, non un ornement :
% elles se composent, elles ne s'extraient pas du scan.
% #1 = hauteur relevee ; #2 = deplacement vertical de son centre.
% HAUTEUR ET PROFONDEUR NULLES : posee sans cela, une accolade de 27 pt
% faisait une ligne de 27 pt de haut, et le rang suivant s'en trouvait
% ecarte — au folio 31, la rangee « egaleso » tombait plus loin de
% « Supereso » que de « infreso ».
% Le centre d'une accolade posee sur une ligne de base tombe sur l'axe
% mathematique, soit 10,4 px au-dessus de cette ligne a 300 dpi : c'est
% de la que se comptent les deplacements releves.
\newcommand{\VUaccolade}[2]{%
  \raisebox{#2}[0pt][0pt]{$\left\{\vcenter to #1{}\right.$}}
% Accolade FERMANTE : celle qui rassemble ce qui est a sa gauche. Au
% folio 31, celle de « maxim / minim » designe « de o ek », a sa droite.
\newcommand{\VUaccoladeD}[2]{%
  \raisebox{#2}[0pt][0pt]{$\left.\vcenter to #1{}\right\}$}}
% Accolade HORIZONTALE, pointe en haut : celle de l'arbre genealogique
% du folio 220, qui rattache quatre noms a un seul. Le fac-simile n'en
% donne qu'une dans tout le volume. Mesure : encre de x 524 a 1063
% (539 px = 45,63 mm), y 1339 a 1355, pointe au milieu exact.
% Comme les accolades verticales, elle est posee sans hauteur ni
% profondeur : sans cela le rang des quatre noms s'ecarterait d'autant.
% #1 = largeur relevee.
\newcommand{\VUaccoladeH}[1]{%
  \raisebox{0pt}[0pt][0pt]{$\overbrace{\hbox to #1{}}$}}

% -------------------------------------------------------------------
% 7. LIGNES D'APPARAT (faux-titre, titre, titres de partie)
% -------------------------------------------------------------------
% Sur ces pages aussi, UNE ligne du fac-simile = UN appel de macro :
% le releve reste ligne a ligne, et les controles peuvent le verifier.
% #1 = corps ; #2 = texte de la ligne.
% #1 = corps ; #2 = interlettrage (1/1000 de cadratin) ; #3 = texte.
% Les deux premiers sont MESURES sur le fac-simile (outils/apparat.py) :
% le corps par la hauteur de capitale, l'interlettrage par la largeur.
\newcommand{\VUcentre}[3]{{\centering\fontsize{#1}{#1}\selectfont
   \textls[#2]{#3}\par}}
\newcommand{\VUsaut}[1]{\vspace{#1}}
% Ligne d'apparat placee a une ordonnee ABSOLUE, comptee depuis le bord
% superieur du papier — c'est ainsi qu'on la mesure sur le fac-simile
% (outils/apparat.py donne l'ordonnee du haut des capitales).
% Chaque ligne occupe une hauteur NULLE : elles sont donc placees les
% unes independamment des autres, et une retouche sur l'une ne deplace
% aucune autre.
% #1 = ordonnee du haut des capitales, depuis le bord du papier ;
% #2 = corps ; #3 = interlettrage ; #4 = texte.
\newcommand{\VUcentreA}[4]{%
  \vbox to 0pt{%
    \vskip\dimexpr #1 - \VUmargeSup\relax
    \hbox to \textwidth{\hss
      \fontsize{#2}{#2}\selectfont\textls[#3]{#4}\hss}%
    \vss}%
  \nointerlineskip}

% -------------------------------------------------------------------
% 7 bis. SIGNATURES DE CAHIER
% -------------------------------------------------------------------
% Un chiffre nu au pied de la premiere page de chaque cahier, a gauche.
% Releve sur tout le volume : feuillets 37, 69, 101, 133, 165, 197, 229,
% soit les folios 33, 65, 97, 129, 161, 193, 225, portant 2, 3, 4, 5, 6,
% 7, 8. Les cahiers font donc 16 feuillets (32 pages) et le premier n'est
% pas signe, comme il est d'usage.
% Le chiffre a la meme hauteur que ceux du folio (27 px) : c'est le corps
% courant. Il se pose a 2,88 mm de la marge de gauche (mediane des sept
% mesures : 2,71 a 3,30 mm).
% L'ordonnee est passee en argument, page par page, comme celle de
% \VUnotes : le chiffre suit la DERNIERE LIGNE de la page, non une
% ordonnee absolue. Sur six des sept pages la justification verticale
% rend la meme valeur, 168,7 mm ; mais le folio 225 finit une section et
% sa page est courte, et son chiffre remonte a 146,4 mm. Une constante
% du volume l'aurait donc trahi.
% Hauteur et profondeur nulles : le chiffre ne pousse rien.
\newcommand{\VUsignatureX}{2.88mm}
\newcommand{\VUsignature}[2]{%
  \vbox to 0pt{%
    \vskip\dimexpr #1 - \VUmargeSup\relax
    \hbox to \textwidth{\hskip\VUsignatureX\relax #2\hss}%
    \vss}%
  \nointerlineskip}

% Filet centre : #1 = largeur.
\newcommand{\VUfilet}[1]{{\centering\rule{#1}{0.4pt}\par}}
% Filet de note : court, cale a gauche.
\newcommand{\VUfiletnote}{{\noindent\rule{25mm}{0.4pt}\par}}

% Folio centre, entoure de deux demi-cadratins, comme « — 26 — ».
% Le folio est place ABSOLUMENT, en hauteur nulle : il ne pousse rien.
% Le corps de texte commence donc toujours exactement a \VUmargeSup,
% que la page porte un folio ou non.
\newcommand{\VUfolio}[1]{%
  \ifx\relax#1\relax\else
    \vbox to 0pt{\vskip\dimexpr\VUfolioY-\VUmargeSup\relax
